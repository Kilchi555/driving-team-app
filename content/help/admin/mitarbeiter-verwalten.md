# Mitarbeiter und Admins verwalten

**Menü: Mitarbeiter** → `/admin/users`

## Liste

- Tabs Mitarbeitende / Admins
- Filter: Benutzer / Alle / Einladungen; Suche; Status (inkl. gelöscht → Wiederherstellen)
- **Staff einladen** (E-Mail; sonst Link kopieren); Einladung erneut senden / erneuern
- **Neuer Staff** / **Neuer Admin**
- Seat-Limit-Hinweise beachten

## Beim Anlegen von Staff

Stammdaten, unterrichtete Kategorien, ggf. Guide-Bearbeitung (`can_edit_guide`).

## Detailseite

Allgemeine Infos, Guthaben, Kategorien, Kursanmeldungen, Zahlungen, Termine; bei Staff zusätzlich Ausweis und Monatsübersicht.
