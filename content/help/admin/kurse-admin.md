# Kurse verwalten

**Voraussetzung:** `courses_enabled`. Menü **Kurse** → `/admin/courses`

## Tabs

- **Kurse** – konkrete Durchführungen
- **Kursarten** – Vorlagen / Typen

## Typische Aufgaben

- Neuer Kurs / Neue Kursart
- Optional **SARI Sync**
- Teilnehmer und Status im Kurskontext
- Online- vs. Barzahlung

**Hinweis:** Ohne aktives Zahlungstool (z. B. Wallee) können Anmeldungen auf Bar fallen – Zahlungseinstellungen unter **Einstellungen → Zahlungen**.
