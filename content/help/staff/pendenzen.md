# Pendenzen erledigen

Tab **Pendenzen** (unten) öffnet das Modal mit Gesamt-Badge.

## Tabs

| Tab | Inhalt |
|-----|--------|
| **Allgemein** | Aufgabenliste mit Priorität und Fälligkeit |
| **Bewertungen** | Offene Lektionsbewertungen (wenn Feature aktiv) |
| **Anfragen** | Buchungsanfragen / Proposals |

## Allgemein

- Priorität: kritisch / hoch / mittel
- Status: **Pendent** → **In Bearbeitung** → **Abgeschlossen**
- Leer: **Keine Pendenzen!** / **Alle Aufgaben erledigt**

## Bewertungen

Liste mit Name, Datum, Terminart, Zahlung, Prioritäts-Badge. Tippen öffnet die Bewertung. Danach ggf. Barzahlungs-Bestätigung oder Prüfungsergebnis.

## Anfragen

1. Eintrag → **Ansehen →**.
2. Blöcke prüfen: Kontakt, Anfrage, Adresse, Zeitfenster, Bemerkungen.
3. **Anrufen** / **E-Mail** nutzen.
4. **Ergebnis dieser Anfrage** setzen, z. B.:
   - Buchung abgeschlossen
   - Nur Beratung
   - Potenzieller Kunde
   - Kein Interesse
   - Nicht erreichbar
5. **Als erledigt markieren** oder **Ohne Angabe erledigen**.
