# Dashboard und Navigation

Dein Arbeitsplatz ist das **Dashboard** mit dem Kalender in der Mitte.

## Untere Tabs

| Tab | Funktion |
|-----|----------|
| **Kunden** / Schüler | Liste öffnen, suchen, Profile bearbeiten |
| **Pendenzen** | Offene Aufgaben, Bewertungen, Anfragen (Badge möglich) |
| **Profil** | Arbeitszeiten, Kalender-Sync, Standorte, Hilfe, Abmelden |

Admins sehen ggf. zusätzlich **Marketing**.

## Deep-Link aus E-Mails

Manche Erinnerungsmails öffnen direkt Pendenzen (z. B. Anfragen). Danach arbeitest du wie gewohnt weiter im Dashboard.
